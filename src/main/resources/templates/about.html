我们的使命

帮助奶茶爱好者做出更健康的选择

奶茶君致力于为用户提供准确的奶茶热量信息和个性化的推荐服务。我们相信，了解热量摄入是健康生活的第一步。

精确热量计算

基于真实数据，精确计算您选择的奶茶热量，包括基底和所有小料

AI智能推荐

结合协同过滤算法和大众喜好，为您推荐最适合的奶茶和小料组合

图片智能识别

上传小料图片，AI自动识别并计算热量，支持模糊和低光照图片

技术栈

Java 17 Spring Boot 3.2 Thymeleaf Bootstrap 5 ECharts 协同过滤算法 百度AI图像识别

数据来源

  • 奶茶热量数据：综合各品牌官方数据及第三方营养数据库
  • 小料数据：基于常见配方计算得出
  • 运动消耗数据：参考《中国居民膳食指南》及运动医学研究
  • 热门排行：综合小红书、抖音等社交平台数据

* 注：所有热量数据仅供参考，实际热量可能因制作方式、原料差异等因素有所不同
